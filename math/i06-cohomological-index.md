# I06 Cohomological index formula

## Requirements

- Primary implementation: `cohomological_index`.
- Express topological index as compactly supported cotangent-cohomology evaluation using the symbol Chern character and complexified-tangent Todd class.
- Derive signs from cotangent orientations, Thom classes, Bott elements, and fundamental-class conventions; prove agreement with K-theory formulas.
- Expose integrality of rational-cohomology evaluation and product/orientation-change comparisons.
