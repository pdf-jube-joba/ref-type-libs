# `topological_k_theory`

Complex-bundle Grothendieck rings, stable isomorphism criteria, contravariant pullback, rank/reduced groups, finite discrete computations.

The base is compact Hausdorff and bundles are complex; arbitrary finite ranks may vary between components.

| Entry | Purpose |
| --- | --- |
| `KTheory.On.K0` | Complex-bundle Grothendieck rings on compact Hausdorff spaces |
| `KTheory.On.Bundle` / `Compare` | General-bundle/projection-class comparisons |
| `KTheory.On.K0.Stability` | Equality of virtual bundles by common trivial stabilization |
| `KTheory.On.Pullback` | Contravariant K0 maps, functor laws and rank compatibility |
| `KTheory.On.Ranks` | Locally constant integer ranks and reduced groups |
| `KTheory.FiniteDiscrete` / `Point` | Integer-function and point-integer ring computations |
