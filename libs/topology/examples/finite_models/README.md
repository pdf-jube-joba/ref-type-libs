# `cohomology_examples`

Finite graphs, torus, real projective plane: groups/products/induced maps.

| Entry | Purpose |
| --- | --- |
| `Graph.On.With` | Finite graphs: Spanning-forest primitives, finite-cochain coordinates by components/chords |
| `Graph.On.Geometry` | Graph realizations: Threefold edge subdivisions as actual finite simplicial complexes, mapped to affine singular simplices |
| `Graph.On.Geometry.Coefficients.Singular` | Graph groups: \(H^0\cong A^c\), \(H^1\cong A^k\), higher vanishing for \(c\) components, \(k=e-v+c\) chords |
| `Circle` | Finite circles: Zero-differential integer chains of rank one in degrees zero/one |
| `Circle.Geometry.FiniteComparison` | Circle comparison: Comparison with actual Euclidean-circle chains |
| `Circle.Geometry.UniversalCoefficient` | Circle universal coefficients: Actual singular short exact sequences for arbitrary integer modules from proved finite comparisons |
| `Circle.Geometry.Loop.Primitive` | Circle loops: Closed singular edges from squared upper semicircles, primitive homology classes |
| `Circle.Geometry.Evaluation` | Circle evaluation: Closed-cochain loop evaluation \(H^1(S^1;A)\cong A\) |
| `Torus.Geometry.Comparison` | Torus groups: Actual \(S^1\times S^1\) compared with tensor circle models |
| `Torus.Geometry.Ring.Primitive` | Torus top degree: Isomorphisms making projection products integral degree-two generators |
| `Torus.Geometry.Ring.Basis` / `UnitBasis` | Torus bases: Two degree-one projection bases, degree-zero unit generators |
| `Torus.Geometry.Ring` | Torus products/swaps: Projection degree-one classes, cups, factor-swap actions |
| `ProjectivePlane.Geometry` | Projective-plane space: Actual \(S^2/(x\sim-x)\), hemisphere quotients/disk-attachment comparisons |
| `ProjectivePlane.With` | Finite projective plane: Cochains with two vertices, three edges, two triangles |
| `ProjectivePlane.Integral` | Integral coefficients: Finite \(H^1=0\), \(H^2\cong\mathbb Z/2\) computations |
| `ProjectivePlane.ModTwo` | Two-element coefficients: Finite degree-one \(u\), \(u^2\ne0\) computations |
| `ProjectivePlane.Geometry.Cohomology` | Projective-plane groups: Arbitrary integer modules: degree-one doubling kernels, degree-two cokernels, higher zero |
| `ProjectivePlane.Geometry.Integral` / `ModTwo` | Actual integral/two-element coefficients: Quotient-space singular groups, generators/nonvanishing |
| `ProjectivePlane.Geometry.ModTwo.Ring` | Projective-plane ring: Actual quotient \(u^2=v\ne0\), \(u^3=0\), degree-zero units |
| `ProjectivePlane.Geometry.Restriction` | Triangle restrictions: Actual two-triangle restrictions, circle-loop degree-one detection, cup compatibility |
| `ProjectivePlane.Geometry.Bockstein` | Projective-plane Bockstein: Actual \(u\) maps to nonzero integral degree-two generators |
| `ProjectivePlane.Bockstein.Finite` | Finite Bockstein: Actual cochain connecting values for \(0\to\mathbb Z\xrightarrow{2}\mathbb Z\to\mathbb F_2\to0\) |
