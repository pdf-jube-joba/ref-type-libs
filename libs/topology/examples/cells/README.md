# Foundational topology examples

Package: `cell_spaces`; the entry point [src/root.ref](src/root.ref) exposes the following examples.

| Module | Contents |
| --- | --- |
| [Algebra](src/Algebra.ref) | Integer group-completion round trips, direct sums, duals, and tensor contraction |
| [Homotopy](src/Homotopy.ref) | Applications of the homotopy APIs |
| [Quotients](src/Quotients.ref) | Quotient-space constructions |
| [Cells](src/Cells.ref) | A one-cell circle attachment, empty finite CW complexes, and disk/sphere closedness |
| [Matrix](src/Matrix.ref) | Matrix examples |
| [Finite](src/Finite.ref) | Finite bases, coordinate homeomorphisms, and dimension invariance |
| [Simplices](src/Simplices.ref) | Simplex coordinates, faces, compactness, contractions, and affine-map laws |
