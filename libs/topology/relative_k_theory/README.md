# `relative_k_theory`

Relative-triple/reduced-group comparisons, negative-degree exact sequences, excision, Mayer–Vietoris, external products, disk/sphere pairs.

APIs are under `Relative` for compact Hausdorff closed pairs. External negative-product degrees are ordered secondDegree + firstDegree.

| Entry | Purpose |
| --- | --- |
| `Relative.Pair.Group` / `Comparison` | Bundle-triple groups and reduced quotient comparisons |
| `Relative.Negative` / `Pair.Augmented` | Negative degrees, five-term exact sequences and naturality |
| `Relative.Pair.Excision` / `ClosedCover` | Excision, closed-cover gluing and Mayer–Vietoris |
| `Relative.Smash` / `Pair.Product` | Relative and negative external products with pullback compatibility |
| `Relative.DiskPair` / `BundleDisk` | Actual bundle disk/sphere pairs and coordinate homeomorphisms |
| `Relative.Pair.BundleTriples` | General-bundle presentations, comparison independence and pullbacks |
| `Relative.PointPair` / `Examples` | Pointed quotient comparisons and rank-zero/one disk examples |
