# `sphere_maps`

Sphere orientations, reflection and circle integer-power degrees.

| Entry | Purpose |
| --- | --- |
| `Circle.Coordinates` / `Powers` | Unit-complex circle coordinates and continuous integer-power maps |
| `Circle.Powers.Actions` / `Degree` | Arbitrary-coefficient cohomology actions and integer degrees |
| `Circle.Roots` / `Quotient` | Square roots and the actual antipodal-circle quotient homeomorphism |
| `Reflection` / `Hemispheres` | Reflection maps, Mayer–Vietoris signs and top-homology actions |
| `Antipodal` / `ZeroAntipodal` | Positive-sphere antipodal degrees and reduced-zero sign actions |
| `ZeroHomology` | Integral reduced S0 generators and endpoint signs |
