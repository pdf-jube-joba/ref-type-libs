# `singular_tensor_dual`

Tensor/Hom comparison using finite dual bases.

The finite-dual-frame comparison requires nonnegative complexes and degreewise finite dual frames only on the first factor; the second need not be finite or bounded.

| Entry | Purpose |
| --- | --- |
| `Over.Finite` | Finite dual frames, including projective frames beyond free bases |
| `Over.On` | Tensor-dual/cochain-total isomorphisms and pure-tensor evaluation |
| `Over.Selected` | Specified-diagonal evaluations and naturality without finiteness |
| `Integer.Convert` / `Singular` | Integral-action comparisons and singular cup evaluation |
| `Over.IntegerCoordinates` | Integer-coordinate duals identified by standard-basis values |
| `Over.Mixed.On` / `Mixed.HomEquivalence` | Mixed integer-chain/commutative-coefficient comparisons and cohomology isomorphisms |
