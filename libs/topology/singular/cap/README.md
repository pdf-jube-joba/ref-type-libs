# `singular_cap`

Cap and relative products, Kronecker evaluation and adjunction formulas.

Caps return front p-faces and evaluate degree-q cochains on back faces of (p+q)-chains. The boundary correction sign is (-1)^p.

| Entry | Purpose |
| --- | --- |
| `Integral.At` | Integral front-face cap maps, generator formulas and cup-evaluation adjunction |
| `Integral.Diagonal.Boundary` / `Natural` / `Unit` | Signed boundary, naturality and unit laws |
| `Integral.Pair` | Relative caps, cohomology actions and connecting-map compatibility |
| `CochainPair` / `RelativeEvaluation` | Relative cups and arbitrary-module Kronecker pairings |
| `Triple.Union.Cover` | Union-relative cups and caps when subspaces are open in their union |
| `ExternalIntegral` | Relative cross products, descent and projection/connecting formulas |
