# `singular_simplicial`

Finite simplicial realizations, affine singular chains and product comparisons.

| Entry | Purpose |
| --- | --- |
| `Complex` | Finite downward-closed vertex complexes and ordered simplices |
| `Complex.On.Realization` | Affine realization, star covers and contractible intersections |
| `Complex.On.Chains` | Affine singular comparisons and arbitrary-coefficient cochains |
| `Complex.On.Chains.HomotopyEquivalence` | Nonnegative/integer equivalences and homology/cohomology comparisons |
| `Complex.On.Coordinates` | Bounded finite-free matrix models and singular-chain equivalences |
| `Complex.On.Cup` | Front/back cup products, Leibniz and compatibility with singular products |
| `Complex.LineGraph` | Graph chains, incidence boundaries and vertex/edge coefficient functions |
