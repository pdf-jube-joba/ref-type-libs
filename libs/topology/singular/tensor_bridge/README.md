# `singular_tensor_bridge`

Integer/nonnegative tensor-complex comparisons.

Factor complexes must vanish in negative degrees; no finite-generation or freeness assumption is required.

| Entry | Purpose |
| --- | --- |
| `Integer.Factor.With` | Negative-vanishing integer complexes compared with zero-extended nonnegative restrictions |
| `Integer.Indices` | Natural/integer diagonal index comparisons |
| `Integer.Tensor.With` | Boundary-compatible tensor-total isomorphisms and equivalences |
| `Integer.Tensor.With.Negative` | Vanishing of negative total terms |
| `Integer.Lift.With` | Lifting nonnegative isomorphisms to integer zero extensions |
