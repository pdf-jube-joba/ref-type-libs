# `singular_cech`

Cover double complexes and projective-complex comparisons.

| Entry | Purpose |
| --- | --- |
| `Algebra.ProjectiveQuasi` | Equivalences from degreewise-surjective projective quasi-isomorphisms with kernel fillings |
| `Algebra.Concentrated` / `Restriction` | Zero-row models and restriction of integer complexes |
| `PartialCone` / `Coproduct` | Simplicial contractions, augmentation fillings and coproduct models |
| `CarrierModel` | Supported chain-map families, closed diagonals and carrier homotopies |
| `Algebra.TensorEquivalence` | Tensor-total equivalences from nonnegative chain equivalences |
