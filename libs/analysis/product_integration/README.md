# `product_integration`

σ-finite product measures, Tonelli, real/complex/finite-dimensional Fubini, Euclidean Borel comparison, convolution integrals/support/L1 estimates.

Products require sigma-finite factors. Euclidean measure equality is on Borel sets; it does not identify the completed product sigma-algebra. Convolution requires joint measurability.

| Entry | Purpose |
| --- | --- |
| `Finiteness` / `ProductSigma` / `Product` | Sigma-finite product measures and rectangle formulas |
| `Integration.tonelli` / `fubini` | Extended nonnegative Tonelli and real a.e. Fubini comparisons |
| `Integration.Complex` / `Vector` | Complex/finite-dimensional Fubini with common null exceptions |
| `Symmetry` / `EuclideanProduct` | Factor swaps and Borel comparison with higher-dimensional Lebesgue measure |
| `Convolution` / `Euclidean.Convolution` | Integrable convolutions, integral products, L1 estimates and support bounds |
| `Examples` | Zero Fubini, convolution and box-comparison examples |
