# `change_of_variables`

Invertible linear measure transformations, compact-support diffeomorphism substitution, localization, parameter integrals, boundary terms, densities/top forms.

Diffeomorphism substitution uses smooth compact-support functions supported in the target open set. Densities use absolute determinants; oriented top forms use signed determinants.

| Entry | Purpose |
| --- | --- |
| `Change.theorem` | Compact-support diffeomorphism substitution with the absolute Jacobian |
| `Linear.Generated` / `Elementary.Elimination` | Linear measure transformation and elementary factorizations |
| `Euclidean.Jacobian` | Signed/absolute Jacobians, composition and inverse laws |
| `Euclidean.Localization` / `Decomposition` | Cutoffs, zero extension and finite compact-support decompositions |
| `Euclidean.Parameters` | Integration/derivative interchange under domination and local uniform bounds |
| `Euclidean.Compact` / `Interval` / `Boundary` | Integration by parts, interval substitution and boundary formulas |
| `Euclidean.Density` / `TopCoordinates` / `TopForm` | Density pullbacks and signed top-form coordinate comparisons |
