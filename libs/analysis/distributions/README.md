# `distributions`

Test-function topology, continuous duals, injection of locally integrable functions, distribution derivatives/support/smoothing, Sobolev comparisons and diffeomorphism pullbacks.

Sobolev comparisons cover whole Euclidean spaces and finite exponents. Compact-kernel smoothing imposes no global growth condition on distributions.

| Entry | Purpose |
| --- | --- |
| `Euclidean.Test` / `TestOperations` | Compact-support smooth tests, partials and iterated jets |
| `Euclidean.LocallyConvex` / `Distribution` | Test topology, continuous duals and finite-order bounds |
| `Euclidean.Regular` | Injective embedding of locally integrable functions modulo a.e. equality |
| `Euclidean.Dual` / `SupportTheory` | Distribution derivatives, convergence and supports |
| `Euclidean.Regular.Sobolev` | Whole-space weak-derivative and finite-order Sobolev comparisons |
| `Euclidean.Convolution` | Smooth compact-kernel convolution and derivative/integral comparisons |
| `Euclidean.On` / `Pullback` | Open-set distributions, restrictions and diffeomorphism pullbacks |
