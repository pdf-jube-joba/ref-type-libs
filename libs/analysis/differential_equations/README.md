# `differential_equations`

Picard integral operators, local ODE existence/uniqueness, smooth solutions of smooth vector fields.

| Entry | Purpose |
| --- | --- |
| `Euclidean.BoundedLipschitzField` | Autonomous vector fields bounded and Lipschitz in maximum norm |
| `Euclidean.On.Step` | Picard operators, fixed-point curves and initial-value/derivative formulas |
| `Euclidean.localExistence` / `localUniqueness` | Local solutions and agreement on common positive intervals |
| `Euclidean.Smooth` | Local existence and uniqueness for smooth vector fields on open sets |
| `Euclidean.Smooth.Regularity` | Smooth maps representing arbitrary smooth-field local solutions |
