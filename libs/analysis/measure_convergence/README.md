# `measure_convergence`

Monotone convergence, Fatou, dominated convergence, a.e.-quotient integration, real/complex/finite-dimensional integration and series interchange.

For incomplete measures, a.e. limit theorems construct measurable integrable representatives. Complex/vector integral estimates use component bounds.

| Entry | Purpose |
| --- | --- |
| `On.monotone` / `FatouFor` | Monotone convergence and Fatou inequalities for lower integrals |
| `On.Dominated` / `AEDominated` | Dominated convergence and a.e.-equal integrable limit representatives |
| `On.IntegralClasses` | A.e. quotient integrals, linearity and order/absolute-value bounds |
| `On.Series` | Dominated pointwise/a.e. interchange of integration and series |
| `On.Complex` / `Vector` | Componentwise integrals, convergence, series and component norm bounds |
| `On.Indicator` / `Examples` | Indicator integrals and convergence/quotient examples |
