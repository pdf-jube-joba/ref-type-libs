# `grassmannian_cells`

Schubert coordinates, finite CW structures, oriented coverings, standard inclusions and stable finite-stage comparisons.

| Entry | Purpose |
| --- | --- |
| `Symbols` / `Echelon` | Schubert symbols, exact cell dimensions and free-coordinate round trips |
| `Real.Canonical` / `Complex.Canonical` | Choice-independent cells and free-coordinate homeomorphisms |
| `DecompositionReal` / `DecompositionComplex` | Echelon reduction, cell coverage and disjointness |
| `CWReal` / `CWComplex` | Standard-disk characteristic maps and finite CW structures |
| `AmbientReal` / `AmbientComplex` | Cellular ambient inclusions and filtration comparisons |
| `OrientedReal` | Two-sheeted oriented coverings and lifted finite CW structures |
| `StableReal` / `StableComplex` | Weak stabilization topology and finite-stage sphere maps/homotopies |
