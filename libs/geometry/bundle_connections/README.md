# `bundle_connections`

Real/complex bundle connections, bundle-valued forms and induced connections, metric-compatible and Levi–Civita connections.

Bases are Hausdorff second-countable finite-dimensional real manifolds. Complex bundle connections are represented on realifications with explicit complex-structure compatibility.

| Entry | Purpose |
| --- | --- |
| `Local` / `Forms` | Local connection matrices, covariant derivatives and bundle-valued forms |
| `Real` / `Complex` | Global connections and existence on smooth real/complex bundles |
| `BundleForms` / `GlobalForms` | Actual bundle-valued smooth sections and covariant exterior derivatives |
| `PullbackGlobal` / `ComplexPullbackGlobal` | Bundle/connection pullbacks and derivative naturality |
| `Induced` / `Exterior` / `ComplexMatrices` | Dual, tensor and exterior connections with frame-change laws |
| `MetricCorrection` / `Metric` / `ComplexMetric` | Metric-compatible and Hermitian connection constructions |
| `LeviCivita` | Local/global Levi-Civita existence, uniqueness and restriction comparisons |
| `Examples` | Rank-zero bundles, constant connections and Euclidean Levi-Civita examples |
