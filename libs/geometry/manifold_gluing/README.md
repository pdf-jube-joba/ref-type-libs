# `manifold_gluing`

Collars, boundary gluing, smooth structures and comparison maps.

Relative collars lie in prescribed neighborhoods; extensions agreeing with arbitrary existing partial collars are not exposed.

| Entry | Purpose |
| --- | --- |
| `CollarEmbedding.On.With.exists` | Transverse push-ins/uniform collars from compactness and actual boundary-chart covers |
| `CollarEmbedding.From.Of` | Open-image homeomorphisms, injectivity, continuous inverses, actual pointwise smooth inverse charts |
| `CollarWidth` | Positive half-open widths inside common time neighborhoods |
| `CollarRelative.On.With.In.exists` | Relative collars contained in prescribed whole-boundary open neighborhoods |
| `CollarComparison` | Smooth comparison on common times of two constructed collars, fixing boundaries |
| `CollarRestriction` | Actual diffeomorphisms on arbitrary small open parameter regions/images |
| `CollarWindow.Core` | Compact closed-time collar regions and time-coordinate criteria |
| `BoundarySigns` / `GluingForms` / `DoubleForms` | Actual-seam orientation comparisons and boundary cancellation |
