# `grassmannians`

Finite Grassmannians, graph coordinates, universal bundles and stabilization.

| Entry | Purpose |
| --- | --- |
| `Real.Model` / `Complex.Model` | Orthogonal-projection models with fixed finite rank, compact Hausdorff topology and local frames |
| `Real.Model.Graph` / `Complex.Model.Graph` | Local graph coordinates, reconstruction and chart homeomorphisms |
| `Real.Family` / `Complex.Family` | Classifying maps from continuous constant-rank projection families |
| `Real.Pullback` / `Complex.Pullback` | Universal-bundle pullback comparisons |
| `ProjectiveReal` / `ProjectiveComplex` | Rank-one projective spaces and universal lines/complements |
| `Real.Model.Stabilization` / `Complex.Model.Stabilization` | Ambient/rank stabilization and universal-bundle comparisons |
| `Examples` | Identity projections, dimension zero and rank-one points |
