# `compact_embeddings`

Compact-manifold embeddings from finite charts/cutoffs, collar-compatible neat embeddings, stabilized relative embedding families.

| Entry | Purpose |
| --- | --- |
| `WeightedChart[n].On[M].At[c,b,within].map` | Zero-extended weighted chart blocks |
| `At.injectiveAtOne` | Equal images imply equal points where cutoffs equal one |
| `At.Plateau[U,open,oneOn].At[x,inside].immersion` | Actual derivative injectivity on plateaus |
| `WeightedChart.On.Vector[m].Of[f,regular].map` | Euclidean maps from smooth scalar coordinates |
| `Finite[n,d].On[M].Of[f,U].build` | Finite-block assembly, separation/derivative injectivity on covered domains |
| `CompactCriterion.Between.Of.embedding` | Embedding criterion for injective immersions from compact domains to Hausdorff manifolds |
| `Compact.On.exists` | Existence including finite chart/cutoff choices |
| `DoubleEmbedding.On.With.Compact.exists` | Doubles and injective one-sided inclusion derivatives |
| `Bridge.Interior` | Comparison of boundary manifolds with empty boundaries to ordinary manifolds |
| `Neat.Height.With.From.Of.Compact` | Global nonnegative heights and exact zero sets |
| `Neat.Height.With.From.Of.Compact.Collapse` | Collar collapse and joint point separation |
| `HeightNormal.On.With.From` | Boundary preservation, normal surjectivity, tangent reflection |
| `CollapseDifferential.On.With.From.joint` | Joint injectivity of collapse/height derivatives |
| `NeatExistence.On.With.Compact.exists` | Existence of exactly collar-compatible neat embeddings |
