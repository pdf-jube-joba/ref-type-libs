# `bundle_operations`

Cocycle gluing, direct sums/tensors/duals/Hom/exterior powers, realification/complexification and pullback.

APIs specialize `Operations.Over[K, field, conjugation, scalar]`; real and complex constructions share the [vector_bundles](../vector_bundles/README.md) topological-field data.

| Entry | Purpose |
| --- | --- |
| `DirectSum` | Product fibers, topology induced from total products, projections, `Of.From.pair`, `Of.Inclusions`, `Of.To.copair` and universality |
| `Tensor` | Existing algebraic tensors, final topology from finite pure sums, `Of.Pure`, `Of.Universal`/uniqueness for continuous bilinear maps |
| `Dual` | Existing functionals, topology generated by continuous-section evaluation, `Pairing` and contravariant `Contramap` |
| `Hom` | Actual existing linear maps, topology transported from \(E^*\otimes F\) via `Of.tensorHom`, continuous `Of.Evaluation`/`Of.Mapping` |
| `Exterior[k]` | Alternating \(k\)-forms on \(E^*\), section-tuple evaluation topology, covariant `Mapping`, continuous `Wedge` |
| `Scalars.Realification` | Real scalar restriction of complex fibers, original-total homeomorphisms, real/imaginary coordinates |
| `Scalars.Complexification` | \(E\otimes_{\mathbb R}\mathbb C\), complex action from real tensors, finite-sum final topology |
| `Operations.Over.Cocycle` / `CocycleFromAtlas` | Cocycle gluing, reconstruction and comparison under cover/frame changes |
| `Operations.Over.DirectSumPentagon` / `TensorPentagon` / `TensorDistribution` | Coherence identities, pullback comparisons and tensor/sum distribution |
