# `spinor_representations`

Clifford modules, spinor representations and Spin/Spin-c actions.

Inner products are conjugate-linear first and linear second; real Clifford multiplication is self-adjoint. General continuity of the standard unitary lift into the Spin-c manifold remains unproved.

| Entry | Purpose |
| --- | --- |
| `Complex.Dimension` | Exterior-algebra spinors, creation/annihilation adjoints and isometric Spin-c actions |
| `Complex.Dimension.RealCoordinates.Clifford.Spin.Phase` | Standard real Clifford actions, projections and determinant characters |
| `Complex.Dimension.UnitaryOrthogonal.CanonicalLift` | Vacuum-fixing unitary lifts and exterior-pullback action comparison |
| `Complex.Dimension.UnitaryOrthogonal.Smooth.FromManifold.On` | Smooth standard lifts from smooth unitary matrix families on manifolds |
| `Over.Direct.Total.Isomorphism` | Tensor/direct-sum spinor comparisons, parity and Clifford-action compatibility |
| `Examples` | Square/adjoint, determinant, zero-dimensional tensor and manifold-lift examples |
