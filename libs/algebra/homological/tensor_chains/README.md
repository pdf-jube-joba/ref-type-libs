# `tensor_chains`

Integer-graded tensor totalization, external products and naturality, signed shifts, commutative squares.

| Entry | Purpose |
| --- | --- |
| `TensorChain.Grading` / `BoundedDiagonal` | Integer degree arithmetic and finite bounded diagonals |
| `TensorChain.Over.Tensor` / `Total` | Tensor double complexes and finite-support totals with signed differentials |
| `TensorChain.Over.Exterior` / `ExteriorTransport` | External homology products and cycle-representative formulas |
| `TensorChain.Over.CycleProductNaturality` | External-product naturality under maps of both factors |
| `TensorChain.Over.TensorMapping` / `TensorSquare` | Induced tensor maps, functor laws and commuting squares |
| `TensorChain.Over.Row` | Signed shifts and homology isomorphisms |
