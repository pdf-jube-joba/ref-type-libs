# `field_kunneth`

Finite free field-coefficient cochain complexes, canonical external-product isomorphisms, naturality, swap signs, units.

Comparisons apply to bounded finite-free field-coefficient cochain complexes and are independent of chosen splittings.

| Entry | Purpose |
| --- | --- |
| `FieldFinite.Over.Of` | Projectivity of cycles/boundaries/cohomology, splittings/contractions |
| `TensorCochain.Over.Total` | Finite diagonal sums, differential \(d_h+(-1)^p d_v\), square zero |
| `TensorMapping` / `HomotopyLeft.With` | Lifting maps/homotopies to total complexes |
| `CycleProduct` / `Exterior.map` | Cycle products, boundary vanishing, cohomological external products |
| `CycleProductNaturality.With.Exterior` / `IndexedExterior` | Both-factor naturality and degree transport |
| `Swap` / `TensorSymmetry.At.Component` | Signed \((-1)^{pq}\) swaps and representative formulas |
| `Kunneth.Field.Of.Canonical` | Isomorphism combining component external products, representative formulas/uniqueness |
| `Canonical.SplittingChange` / `Mapping.With.At` | Splitting changes, two-way naturality of canonical isomorphisms |
| `Kunneth.Field.Of.Symmetry` / `Unit` | Swap signs and left/right unit laws |
| `Kunneth.Field.Assertions` | Theorems universally quantifying complexes, maps, and degrees |
